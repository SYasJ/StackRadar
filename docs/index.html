FAQ

Does StackRadar send my data anywhere?

No. It runs entirely on your computer, listens only on 127.0.0.1 and has no telemetry. Network calls happen only when you click to check or install package updates, or to check for a StackRadar update.

Which AI coding agents does it detect?

Claude Code, Codex CLI, Hermes Agent, OpenClaw, Paperclip, Gemini CLI, Cursor, Windsurf, GitHub Copilot CLI, OpenCode, Goose, Aider, Qwen Code, Amp, Kiro, Continue, Cline/Roo, Ollama and LM Studio.

Can StackRadar block an app from connecting to the internet?

Yes. Apps started from StackRadar run behind its Network Guard, which asks before every new destination (Low / Medium / Strict). Any other app can be blocked per host at the OS firewall with one click and an admin prompt.

Do I need Python?

Not for the desktop app. From source you need Python 3.9+ and no extra packages.

Can I turn off hints or features I don't need?

Yes. Flip the Hints switch in the top bar, and hide whole tabs in Settings → Features.

Will it delete or kill things by accident?

Deletes go to the Trash / Recycle Bin, and permanent delete needs the folder name typed. Kill only targets processes inside your scanned projects.
